# Pet Store API Automation

## 🚀 Overview
Automated API testing suite for the Swagger PetStore API using industry-standard tools.

## 🛠️ Tech Stack
- **Tools:** RestAssured, Java, TestNG, Maven
- **Design Pattern:** Page Object Model (POM)
- **Reporting:** HTML Reports / Allure Reports

## ✨ Key Features
- REST API validation
- JSON Schema verification
- Data-driven testing
- Detailed HTML reports

## ⚙️ Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shubham00117/PetStoreAutomation.git
   ```
2. Navigate to the project directory.
3. Install dependencies (refer to project config files).

## 📊 Usage
Run tests using the standard command-line tools for the tech stack (e.g., `npm test`, `mvn test`, or `pytest`).
